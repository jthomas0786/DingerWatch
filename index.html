All game, roster, player, pitcher, and weather data is loaded from slate.json, rebuilt each morning by build-slate.js against the MLB Stats API and Open-Meteo. Because it's server-generated and served same-origin, it doesn't depend on the browser making cross-origin calls — and stats, trades, and injuries self-correct daily rather than needing manual updates. Live in-game score, inning, count, and batter/pitcher still poll the MLB Stats API directly, since a daily build can't cover in-progress games. Statcast metrics appear when the optional enrichment step has run; otherwise contact-quality values are derived from season rate stats and are flagged as such. Odds are not included — no free public sportsbook feed exists. Everything here is modeled and directional, for entertainment only, not betting advice.
